# 证据与口径契约

## 每次任务先锁定

- 业务对象：品牌、产品、SPU（如有）、商业类目、关键词或目标人群。
- 时间范围与粒度；环比/同比不得混用不同窗口。
- 数据来源：灵光 Skill、模块、任务或导出物。
- 指标原名、计算方式、单位、筛选条件与可追溯位置。

## 实体与数值边界

- 商业类目必须由平台返回；消费者搜索语言不能伪装为商业类目。
- 品牌、SPU、类目和人群包 ID 必须由当前平台查询确认；历史 ID、相似名称和包名都不是映射证据。
- `rankTotalV2 --no-structured` 的类目全量词排行，与 `upDownStreamWord` 的路径 `searchNum` 不能混用。
- 低基数高波动词只作为待验证信号，不能单独据此加码。
- 人群包规模与两两交集，不等于最终去重可投覆盖、曝光、转化或收益。

## 标签定义

| 标签 | 可使用条件 |
| --- | --- |
| 【平台事实】 | 页面、任务或导出物直接显示。 |
| 【计算结果】 | 写明原始数据、公式和计算窗口。 |
| 【合理推断】 | 有证据支撑，但平台未直接证明。 |
| 【策略建议】 | 基于事实与推断提出的行动。 |
| 【待确认】 | 当前不可验证，或需投放端/用户补充。 |

## 失败处理

记录报错现象、尝试路径与最小替代验证；不要盲目重试或把未返回的数值补齐。
