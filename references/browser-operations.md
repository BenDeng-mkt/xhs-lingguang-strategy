# Chrome 与灵光操作

通过用户当前已登录的 Chrome 正常界面操作。浏览器接入由 `$chrome:control-chrome` 完成；优先顺序：当前页面 → 同项目灵光主会话 → 历史任务/产出物 → 候选 Skill 说明。

不要要求用户先手动新开灵光页面。先按 [bootstrap.md](bootstrap.md) 检查已存在标签；没有标签时，使用正常 Chrome 导航到已记录的官方入口地址。首次没有已记录入口时，才要求用户提供一次入口地址或在 Chrome 中打开它。

## 主会话规则

- 同一项目默认续接一个灵光主会话，避免为每个原子新开聊天。
- 本地研究日志用于隔离证据和版本，不等同于需要隔离灵光对话。
- 进入页面前先观察，不要覆盖用户正在编辑的输入。

## 等待与监控

- 每次提交后记录任务标识、提交时间和预期产物。
- 任务仍在生成时只更新状态，等待后再次查看同一任务。
- 完成后立即核验对象、时间、指标、口径和异常，并写入任务卡。
- 连续两次无状态变化：记录失败，并仅尝试一次最小替代验证；禁止重复提交原任务。

## 禁止动作

不得绕过登录、验证码、权限、付费、频控或安全机制；不得读取、展示或保存 Cookie、令牌、接口密钥或账号凭证。
