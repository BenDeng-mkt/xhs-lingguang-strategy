# xhs-lingguang-strategy

用已登录 Chrome 中的“小红书灵光 / 灵犀”可见结果，完成可复核的投放前诊断，并装配为小红书竞价定向策略。

## 适用范围

- 验证灵光可用 Skill、字段、时间范围与数据口径；
- 围绕品牌、产品、类目、关键词和人群完成投放前研究；
- 把前策人群转成“内容角度 × 人群 × 词包”的测试组；
- 将已验证的策略装配包交给 `$ppt-master` 输出 PPTX。

不用于绕过登录、权限、付费、频控或安全机制；不自动创建、修改、推送人群包；不承诺预算、KPI、最终可投覆盖或转化效果。

## 核心方法

```text
语境 = 内容角度 × 人群 × 搜索/比较语言
```

先定义类目与需求语境，再选择人群；先以核心、对照、承接组验证，再考虑扩量。人群包规模、包名、交集和搜索路径计数都不是效果结论。

## 快速使用

在 Codex 中直接说：

```text
用 $xhs-lingguang-strategy 研究 <品牌/产品> 的小红书投放前诊断。
目标：<要决策的问题>。
时间范围：<日期或窗口>。
```

若产品无 SPU，提供品牌、业务类目、核心卖点和使用场景即可。Skill 会先运行 Bootstrap：自动检查并续接当前 Chrome 中的灵光主会话；没有灵光标签时，会使用已确认入口地址在当前 Chrome 打开。首次缺少入口地址，或需要登录/验证码时，才需要用户介入。

## Bootstrap：新项目如何进入灵光

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| `ready` | Chrome 与灵光主会话可用 | 直接进入最小策略原子。 |
| `login-required` | 页面要求登录/验证码 | 用户完成登录后继续。 |
| `browser-unavailable` | Chrome 控制未连接 | 在 Codex 设置中连接 Chrome。 |
| `project-input-required` | 缺研究对象或业务问题 | 补最小输入。 |
| `entry-url-required` | 首次尚无确认的灵光入口地址 | 用户提供一次入口地址，后续复用。 |

## 工作模式

| 模式 | 用途 |
| --- | --- |
| `explore` | 建立灵光能力地图，核验候选 Skill 与输出。 |
| `collect` | 围绕一个对象做小样本、低消耗取数。 |
| `validate` | 对实体、字段、口径、趋势和重叠做交叉验证。 |
| `assemble` | 将通过的策略原子组装为定向测试结构。 |
| `deliver` | 输出策略文档、定向表或交接 `$ppt-master`。 |

## 策略原子

1. 类目需求地图：确认商业类目、消费者搜索语言和词口径。
2. 品牌/竞品比较语境：识别用户需要比较与证明什么。
3. 人群机会地图：按核心种子、场景对照、细分承接组织候选人群。
4. 重叠与渗透验证：识别冗余，设计独立测试。
5. 词包与测试规则：分层组织入口、证明、品牌承接与竞品验证词。

详细输入、输出与通过条件见 [references/strategy-atoms.md](references/strategy-atoms.md)。

## 证据规则

所有结论必须标为以下之一：

- 【平台事实】页面、任务或导出物直接呈现。
- 【计算结果】有原始数据和明确公式。
- 【合理推断】有证据但未经平台直接证明。
- 【策略建议】由事实与推断导出的行动。
- 【待确认】当前无法验证或需在投放端确认。

尤其注意：`rankTotalV2 --no-structured` 的类目全量词排行，与 `upDownStreamWord` 的路径 `searchNum` 不可混用；人群包规模不等于最终可投覆盖。完整规则见 [references/evidence-contract.md](references/evidence-contract.md)。

## 操作节奏与权限

同一项目默认续接一个灵光主会话，并在任务等待期间检查原任务状态，避免重复提交。只读、小样本和低消耗验证可连续推进；建包/改包/推包、上传、分享、批量高消耗任务、修改平台设置或删除产出，必须先获得确认。

## 输出与 PPT

每次交付固定包含：结论摘要、已执行内容、证据与口径、产出物、局限与风险、下一步建议。

需要演示材料时，先生成策略装配包，再调用 `$ppt-master`；PPT 只表现已验证结论，不反向补造数据。装配格式见 [references/delivery-assembly.md](references/delivery-assembly.md)。
